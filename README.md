# 🎰 Life Decision Spinner

A simple and fun web app that helps you make random decisions when you can't choose.

Just add your options, spin the wheel, and let fate decide. 🎯

## ✨ Features

* 🎡 Interactive spinning wheel
* ➕ Add your own choices
* 🎯 Random decision selection
* 🎉 Confetti when a decision is made
* 📜 Decision history
* 🔄 Reset the spinner
* 📱 Simple responsive design

## 🛠️ Built With

* HTML
* CSS
* JavaScript
* Canvas Confetti

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/malavikasanthikrishna06-coder/life-decision-spinner.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! No backend or installation required.

## 🎮 How to Use

1. Enter a choice in the input box.
2. Click **Add**.
3. Add at least two choices.
4. Click **🎯 SPIN**.
5. Let the wheel decide for you!
